# Title

To run program type `python app.py` in console.

## Description

This project was made by Dassine, Alex and Kai.

We were all beginners once. Programmers are not an exception to that. In order to access to others projects or to get our work reconized by companies or by other users, programmers post their code on a webside like Github. However, there is an issue: beginners are usually lost when it comes to manipulate Github because a lot of Githubs' documentation are not as accesssible as we might think they are. Indeed, documentation is not organized in a way a beginner would understands it by the fact that there are a lot of documentation at once, which is intimidating for a beginner. That's why we got a revolutionnary solution: creating a simple webside that allows users to access the information they need by the use of a search bar in order to research the Github. We also added three useful buttons at the bottom of the webside: a download button, a visit button and a documentation button. The download button allows the user to download the operator system they usually use on their computer in order to install a compatible version and compatible commands for their computer. The doumentation button opens the official documentation webside of Github. The visit button opens the main page of Github repositories. 


## Set Up Project

> ### Dependencies
> 
> Dependencies are stored in the `requirements.txt` file

> ### Environment
>
> Copy .env.example file into .env <br>
> Create a secret key using the steps int the .env.example

> ### Installing Requirements
> 
> ##### Windows
> `python -m venv .venv`<br>
> `.venv/Scripts/activate` *(You should see a (env) if not try with .bat at the end)*<br>
> `pip install -r requirements.txt`<br>
> 
> ##### Linux
> 
> `python3 -m venv .venv`<br>
> `source .venv/bin/activate`<br>
> `pip install -r requirements.txt`<br>
>
> ##### Adding Dependencies
> 
> `pip install {dependency}`<br>
> `pip freeze > requirements.txt`<br>
